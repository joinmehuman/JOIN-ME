# JOIN ME／問いの鏡

自分を決めつけず、いまの状態と言葉を見つめるための自己観察プロダクトです。

## 重要：このGitHubは正本ではありません

現在の正式プロダクトは ChatGPT Sites 側で管理しています。
このリポジトリは **履歴・参照用アーカイブ** であり、JOIN ME／問いの鏡の最新仕様、最新料金、現在のUI、現在の公開状態を決めるSource of Truthではありません。

最新判断は次の2つだけを基準にします。

1. 最新版マスター仕様書：何を作るか
2. 正式Sites：現在、実際に何が動いているか

このGitHub内の古い料金、旧UI、旧市場設定、過去の試験結果を正式Sitesへ逆流させないでください。

## 公開状態

GitHub Pagesによる簡易体験版の公開は、2026年8月25日に終了しました。

正式なSites版は別プロジェクトで管理しており、このGitHubリポジトリからは配信しません。

## 保存しているもの

- `config/`：過去の市場・危機支援設定の記録
- `legal/`：日本公開前に作成した法務確認資料の履歴
- `security/`：GitHub Pages版で実施した過去の試験結果
- `tests/`：GitHub Pages版の過去の検証コード
- Git履歴：削除前の公開ファイルを復元可能
- `archive/pre-cleanup-2026-08-25`：整理前コードの保存ブランチ

`config/`、`legal/`、`security/`、`tests/`はいずれも履歴資料です。現在の正式Sites版の仕様・料金・公開可否を直接制御しません。

## 運用ルール

- 正式SitesはこのGitHubから配信しない
- 正式SitesのUI修正判断にこのリポジトリの旧実装を使用しない
- 最新版マスター仕様書と正式Sitesを正本とする
- GitHubは削除せず、必要な場合だけ履歴確認に使う
